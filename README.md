# Tempo

Tempo ist ein einfacher Habit Tracker und Tagesplan mit Kalender, Statistiken und Dark Mode. Gewohnheiten und Zeitpläne lassen sich an den eigenen Alltag anpassen.

## Daten & Privatsphäre

Tempo speichert Gewohnheiten, Haken, Zeitblöcke und Darstellung nur im jeweiligen Browser. Es gibt keine Konten, Cloud-Synchronisierung oder zentrale Datensammlung. Andere Personen können lokale Einträge nicht sehen.

## Website veröffentlichen

Dieses Repository enthält die allgemeine Version. Zum Veröffentlichen: Öffne **Settings → Pages**, wähle **Deploy from a branch**, Branch **main** und Ordner **/(root)**. Die öffentliche Website-Adresse erscheint anschließend in den Pages-Einstellungen.
